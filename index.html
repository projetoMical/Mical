Sobre o MICAL

O MICAL foi desenvolvido com o objetivo de auxiliar os moradores no acompanhamento do consumo residencial de água e energia elétrica. Por meio dos dados coletados pelos sensores, a proposta é apresentar informações que ajudem o usuário a compreender seus hábitos e identificar possíveis situações de desperdício.

Dúvidas frequentes

Entenda a proposta e o funcionamento do MICAL.

O que é o MICAL?

É uma proposta de sistema de Monitoramento Inteligente de Consumo de Água e Luz, que auxilia moradores a acompanhar o consumo residencial.

Qual é o objetivo do MICAL?

Fornecer informações para ajudar o usuário a compreender seus hábitos, identificar possíveis desperdícios e buscar uma utilização mais consciente dos recursos.

Como os dados são obtidos?

O projeto utiliza sensores conectados a um ESP32 para coletar informações de consumo. Os dados deverão ser enviados a uma API para processamento e armazenamento.

O MICAL envia alertas?

Estão previstos alertas relacionados a situações como consumo anormal.

Posso visualizar gráficos de consumo?

Sim. A proposta apresenta os dados por meio de gráficos e informações organizadas, permitindo acompanhar a evolução do consumo.

O sistema mostra quanto vou pagar?

O projeto prevê estimativas de despesas. Os valores devem ser entendidos como estimativas, não como substituição da conta oficial.

O MICAL fornece dicas de economia?

Sim. Uma das propostas é apresentar dicas para incentivar o uso consciente da água e da energia elétrica.

O MICAL funciona em celular?

O site é responsivo e deve se adaptar a diferentes tamanhos de tela, incluindo celulares e tablets.

Preciso instalar algum programa?

O acesso às funcionalidades web ocorre pelo navegador. Os recursos que dependem dos sensores necessitam da integração com os dispositivos e com a infraestrutura do projeto.
